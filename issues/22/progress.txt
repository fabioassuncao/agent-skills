## Codebase Patterns
- Pacote real fica em `packages/issue-flow/` (monorepo); rodar npm scripts a partir desse diretório
- Escrita atômica de JSON: mkdtemp em os.tmpdir() + writeFile + rename, com fallback copyFile+unlink para EXDEV (padrão de `saveTaskPlan` em src/core/state-manager.ts)
- Strip de ANSI: usar `stripVTControlCharacters` de node:util (Node >= 22), não regex manual
- Lint/format: biome — rodar `npx biome check --write src/` antes de commitar (formatter é estrito: quebra ternários longos)
- Testes: vitest, arquivos `*.test.ts` colocados ao lado do código em src/ (excluídos do tsc via tsconfig exclude)
- Timestamps: `isoNow()` de state-manager.ts (ISO sem milissegundos); eventos carregam `at: string` para manter reducers puros
- Callback de stories no engine: `getStoryUpdateCallback()` recebe `UserStory[]` completo (src/core/engine.ts:282)
- Zod 4 (^4.3.6): schemas em src/schemas.ts; usar `satisfies z.ZodType<Interface>` para travar schema ↔ interface TS; defaults via `.default()` fazem `parse({})` materializar a config padrão
- Config em camadas: validar cada fonte parcial com `schema.partial().safeParse()` (defaults NÃO são aplicados), mergear por spread na ordem de precedência e parsear o merge com o schema completo no final
- Slots globais de CLI: padrão setX() em módulo (como setVerbose em core/verbose.ts) — flags extraídas no hook preAction de cli.ts (ex.: setWebCliOverrides em config.ts)
