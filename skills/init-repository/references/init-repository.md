# Initialize repository conventions

Read repository-policy and repository-scaffold. Discover what is already declared, including organization templates where applicable. The optional CLI integration can supply a plan, but direct inspection is a complete supported path.

Produce a concrete plan of create, keep and review actions, with paths, reasons and required/recommended/contextual tiers. Keep existing templates, documents and taxonomies. An existing alternative is not a missing default. Conflicting instructions are review findings, not permission to replace them.

Render candidate assets with the bundled scaffold helper, which uses the canonical defaults and renderers. Select only missing approved files; the helper's full output is a candidate catalogue, not an instruction to create every file. Use existing documentation paths for the AGENTS index.

Apply authorized create actions only. Immediately recheck destination existence, avoid symlink destinations and use exclusive creation. If a file appeared since planning, keep it and report the changed plan. A second run must create nothing.

Do not copy organization templates into the project. Do not overwrite an existing label registry, create remote labels, or auto-migrate existing CLAUDE.md instructions. Propose promotion to AGENTS.md separately, preserving content, and act only on authorization. Return created, preserved and unresolved paths with reasons.
